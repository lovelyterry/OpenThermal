# OpenThermal 红外热成像使用手册

当前版本：`v4.0.6`

OpenThermal是一款红外热成像系统。 支持 Wi-Fi 无线连接与 USB Type-C 有线直连，可在浏览器、Windows 桌面端及 Android 移动端实时查看热成像画面与测温数据。

**已适配硬件**：
- `INFRARED-MINI`：无屏便携版
- `INFRARED-PRO`：带屏手持版
- 更多硬件适配中...

## 连接方式

### 1. 无线连接（支持 AP 模式与 STA 模式）

1. **AP 模式（设备热点）**：设备通电后默认开启名称为 `INFRARED-xxxxxx` 的无密码 Wi-Fi 热点，手机或电脑直接连接该热点即可使用（可在【系统设置】中开关热点或修改热点名称与密码）。
2. **STA 模式（连接路由器）**：在【系统设置】->【无线局域网】中连接目标 Wi-Fi 并保存，设备即可接入家庭或办公局域网；设备会自动记住常用网络，下次重连时优先选择信号最好的网络。
3. **网页控制**：在 **AP 模式**下浏览器访问 `http://192.168.4.1`，或在 **STA 模式**下访问设备在局域网中的 IP 地址即可使用（默认账号 `admin`，密码为空，可在【系统设置】中修改）。
4. **客户端连接**：打开桌面端或手机端应用后会自动搜索附近设备，点击即可连接，也支持手动输入 IP 连接。

### 2. 有线连接

- **电脑端**：使用 Type-C 数据线将设备直接连到电脑，打开 [`OpenThermal.exe`](./OpenThermal.exe) 即可自动识别并显示画面。
- **手机端**：Android 手机可通过 Type-C 数据线直接连接设备使用。

## 主要功能

- **图像与调色板**：提供多种插值平滑滤波算法与伪彩调色板，支持颜色反转、90°/180°/270° 旋转、水平/垂直镜像，以及最小温差跨度和百分位拉伸调节。
- **视觉融合**：支持在 [`OpenThermal.apk`](./OpenThermal.apk) 与 [`OpenThermal.exe`](./OpenThermal.exe)（需连接摄像头）中开启**视觉融合**开关，将可见光摄像头画面与红外热成像实时同频融合。提供多种融合方式，目前处于实验阶段，需要用户自行调节参数。
- **测温与显示**：自动追踪最高温、最低温与定点温度并计算全画幅平均温度，三个光标均支持独立开关、样式切换与温度标签字号缩放；支持 ℃ / ℉ / K / °Ra 切换、0.01~1.00 发射率调节。
- **图像增强与设置**：支持AI画质增强、Gamma 曲线调节，选择各种滤波器及伪彩色方案。
- **数据统计与导出**：持久化记录温度、帧率与电池电压历史曲线，支持时间轴缩放、平移与导出数据。
- **截屏与录像**：支持保存带测温标线的 PNG 截图与录制 MP4 视频。
- **传感器校准方法**：用温度均匀的平整物体遮挡镜头，在【系统设置】中点击“传感器一致性校准”即可消除底噪。

### 快捷手势

- **桌面端 / 移动端 / 网页端**
  - 上下滑动：切换伪彩调色板
  - 左右滑动：切换插值滤波器
  - 点击画面：移动定点测温位置
- **带屏手持机型实体屏**
  - 上下滑动：切换伪彩调色板
  - 左右滑动：切换侧边信息栏停靠在左侧或右侧
  - 点击画面：移动定点测温位置
  - 长按屏幕：进入系统设置
  - 长按电源键 2 秒：开机或关机
  - 短按电源键：冻结或恢复实时画面

## 固件升级与 DIY 恢复

官方固件（`infrared-mini`、`infrared-pro`）及固件烧录、全片擦除、设备密钥备份功能均已**直接内置**于 [`OpenThermal.exe`](./OpenThermal.exe) 与 [`OpenThermal.apk`](./OpenThermal.apk) 中，无需额外下载固件文件或使用独立升级工具：

1. **备份原厂密钥**
   - 用 Type-C 数据线（或 Android OTG 线）连接设备与客户端，切换到 [`OpenThermal.exe`](./OpenThermal.exe) 或 [`OpenThermal.apk`](./OpenThermal.apk) 的“固件升级”页面，检测到设备后点击**备份**，即可读取并保存设备密钥。
2. **刷写固件**
   - 在固件选择框中选择对应产品型号（`infrared-mini` 或 `infrared-pro`），点击**升级**即可直接写入内置官方固件；如需彻底清空芯片，可使用界面中的**擦除**功能（擦除及升级前均会自动检查并备份本地密钥）。
3. **恢复官方系统**
   - 在界面中填入或自动加载已备份的设备授权密钥后，选择对应产品型号执行**升级**，即可恢复出厂授权。

## 常见问题

- **连上热点后 `http://openthermal.local` 打不开**：部分手机或电脑不支持该局域网域名，请直接访问 `http://192.168.4.1`。
- **手机连上设备 Wi-Fi 后页面无响应**：系统提示“当前 WLAN 无互联网连接”时请选择“保持连接”，并暂时关闭移动数据或“自动切换最佳网络”功能。
- **电脑无法识别 USB 串口**：请先关闭其他可能占用串口的软件；如设备管理器仍未出现 COM 口，请检查数据线是否支持数据传输或安装对应 USB 串口驱动。
- **安卓手机 OTG 连接无反应**：部分安卓手机默认关闭 OTG 供电，请在手机系统设置中手动开启 OTG 功能。
- **忘记登录密码**：可使用 [`OpenThermal.exe`](./OpenThermal.exe) 或 [`OpenThermal.apk`](./OpenThermal.apk) 进行全片擦除后重新烧录固件解决（擦除前请先备份授权密钥）。

## 注意事项

- 严禁将镜头直接对准太阳、焊接电弧或高功率激光等强辐射源，否则会造成红外传感器永久损坏。
- 镜头表面带有精密光学镀膜，勿用手指直接触碰或使用尖锐物擦拭，清洁时请使用气吹或专用镜头纸。
- 测温距离与目标尺寸有关，被测目标在画面中占用的像素越多，测温越准确。
